데이터 기반 구축2020–2021

설비 마스터 데이터 플랫폼

설비 식별자·생애주기 업무를 표준화하고 업무 시스템 간 ETL·EAI를 연결하는 중앙 데이터 플랫폼을 구축했습니다.

운영주 개발자 · 시스템 엔지니어

업무 흐름 이해를 돕기 위해 AI로 생성한 컨셉 이미지이며 실제 시스템 화면은 아닙니다.

~700지원 사용자
87%보고된 업무 효율 개선
2020–21구축 기간
개선 전후 ↓처리 흐름 ↓개발 영역 ↓개선 결과 ↓

산업기술보호법 및 회사 보안정책에 따라 세부 구현은 공개하지 않으며, 프로젝트의 전체적인 컨셉과 접근 방식만 설명합니다.

01 / 무엇이 달라졌나

업무 흐름의 개선 전후.

개선 전

같은 설비, 서로 다른 데이터.

  1. 1시스템별로 설비 데이터 관리
  2. 2식별자 수작업 대조
  3. 3누락·중복 데이터 개별 수정

품질·정비·작업 시스템에서 같은 설비에 대한 정보가 일치하지 않을 수 있었습니다.

개선 후

공통 식별자와 일관된 생애주기.

  1. 1식별자·업무 흐름 표준화
  2. 2데이터 검증·연계
  3. 3데이터 품질·연계 상태 모니터링

중앙 플랫폼에서 업무 규칙·검증·후속 활용을 연결해 반복 대조에 의존하던 흐름을 개선했습니다.

02 / 업무 흐름 속 기술

정보가 시스템을 통과하는 과정.

단계를 선택하면 목적, 구현 기술, 운영상 보호 장치를 확인할 수 있습니다.

공통 기준 정의

Asset identifiers + lifecycle

품질·정비·작업 시스템 간 설비 식별자와 생애주기 업무 기준을 정리합니다.

데이터를 연계하기 전에 관리 주체와 필수 정보를 명확하게 합니다.

마스터 데이터 검증

SQL + validation rules

중앙 설비 데이터 모델에서 누락·중복·불일치를 식별합니다.

식별자 충돌을 임의 병합하지 않고 검토할 수 있도록 표시합니다.

업무 시스템 연계

ETL / EAI

검증된 정보를 플랫폼과 연계 업무 시스템 사이에서 전달합니다.

연계 실패와 마스터 데이터 품질 문제를 별도로 추적합니다.

품질 모니터링

BI dashboards

지속적인 운영 조치를 위해 데이터 품질과 연계 상태를 시각화합니다.

수정에 필요한 시스템 맥락과 조치 가능한 예외를 제공합니다.

03 / 직접 개발한 영역

설계하고 개발하고 운영한 영역.

PythonSQLData modellingETL / EAIBI monitoring

플랫폼·DB 설계

중앙 설비 데이터 플랫폼을 설계·개발하고 식별자와 생애주기 업무 흐름을 표준화했습니다.

검증·ETL·EAI

시스템 간 누락·중복·불일치를 식별하는 검증 기능과 연계 기능을 개발했습니다.

운영 품질 모니터링

데이터 품질·연계 문제를 확인하고 후속 조치할 수 있도록 BI 모니터링을 추가했습니다.

설계의 핵심 판단

테이블을 공유하는 것만으로 데이터가 일관되지는 않습니다. 공통 식별자, 생애주기 규칙, 검증, 연계 가시성이 함께 작동해야 합니다.

예외·검증 시나리오

필수 값 누락 · 식별자 충돌 · 반복 수집 · 수정 반려 · 연계 실패

04 / 개선 결과

실무에서 달라진 결과.

업무 흐름 표준화·검증·시스템 연계로 약 700명의 사용자를 지원했으며, 마스터 데이터 업무 효율 87% 개선이 보고됐습니다.
