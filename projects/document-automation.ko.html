도면 납품 자동화2025–2026

엔지니어링 도면 납품·데이터 플랫폼

메일로 주고받던 도면 납품을 접수·추출·검증·데이터 연계가 이어지는 플랫폼으로 전환했습니다.

운영주 개발자 · 기술 프로젝트 리드

업무 흐름 이해를 돕기 위해 AI로 생성한 컨셉 이미지이며 실제 시스템 화면은 아닙니다.

30–70kFAB당 도면
~10kFAB당 등록 자산·컴포넌트
2025–26플랫폼 구축 기간
개선 전후 ↓처리 흐름 ↓개발 영역 ↓개선 결과 ↓

산업기술보호법 및 회사 보안정책에 따라 세부 구현은 공개하지 않으며, 프로젝트의 전체적인 컨셉과 접근 방식만 설명합니다.

01 / 무엇이 달라졌나

업무 흐름의 개선 전후.

개선 전

여러 담당자와 반복되는 메일.

납품 담당현업 담당검토 담당
  1. 1메일로 도면 제출
  2. 2파일·목록 수기 검수
  3. 3보완 요청 후 다시 제출

버전, 누락 정보, 검토 상태가 메일과 수작업에 분산돼 있었습니다.

개선 후

한 번의 제출로 이어지는 처리 흐름.

도면 제출자동 처리결과 검토
  1. 1접수·버전 관리 일원화
  2. 2데이터 추출·규칙 자동 검증
  3. 3오류 검토 후 자산 데이터 등록

FastAPI·Vue.js 화면에서 납품 추적, 검증 결과, 오류 관리를 한곳에서 확인합니다.

02 / 업무 흐름 속 기술

정보가 시스템을 통과하는 과정.

단계를 선택하면 목적, 구현 기술, 운영상 보호 장치를 확인할 수 있습니다.

접수·버전 관리

AWS S3 + EventBridge

제출 도면을 저장하고 파일 도착 이벤트를 처리 흐름에 연결합니다.

파일 식별자와 버전 정보를 처리 상태와 함께 관리합니다.

큐잉·처리

SQS + Lambda

파일 접수와 처리를 분리해 이벤트 기반 파이프라인으로 추출 작업을 수행합니다.

실패 작업을 별도로 추적해 재시도 시 원래 제출 이력을 놓치지 않도록 합니다.

도면 데이터 추출

APS APIs

도면 API를 통해 문서·객체 정보를 추출하고 검증·연계 가능한 데이터로 변환합니다.

원본 참조를 유지하고 추출 오류와 업무 규칙 위반을 구분합니다.

검증·구조화

Python + FastAPI + SQL

납품 완전성, 식별자, 정합성을 검증하고 구조화된 결과와 업무 상태를 저장합니다.

중복·누락·불일치를 조치 가능한 오류로 표시합니다.

검토·오류 조치

Vue.js + REST APIs

현업 사용자를 위한 납품 추적, 검증 결과, 오류 관리 화면을 제공합니다.

수정·재제출 과정에서도 도면별 진행 상태와 오류 맥락을 확인할 수 있도록 합니다.

등록·후속 연계

Master data + ETL/EAI

검증된 엔지니어링 정보를 마스터 데이터와 후속 시스템에 연결합니다.

검증 상태와 연계 상태를 구분해 운영자가 후속 조치를 판단하도록 합니다.

03 / 직접 개발한 영역

설계하고 개발하고 운영한 영역.

PythonFastAPIVue.jsAWS S3LambdaEventBridgeSQSAPS APIsSQLLinux / Nginx

백엔드·데이터 모델

DB와 FastAPI 서비스, 추출·연계 파이프라인을 설계하고 현업 요구를 검증 규칙으로 구현했습니다.

프론트엔드·오류 처리 흐름

납품 추적·검토 결과·오류 조치용 Vue.js 화면을 개발하고 사용자 작업을 백엔드 상태에 연결했습니다.

AWS 이벤트 처리

S3·EventBridge·SQS·Lambda로 파일 저장, 도착 이벤트, 처리 작업을 연결했습니다.

CI/CD·운영 책임

CodePipeline에서 CodeCommit·CodeBuild·CodeDeploy를 연결하고 Linux·Nginx 배포, 로그 분석, 장애 대응까지 담당했습니다.

설계의 핵심 판단

핵심은 파일 접수, 정보 검증, 후속 등록의 경계를 나누는 것입니다. 상태를 구분해 부분 실패를 드러내고 복구 경로를 유지합니다.

예외·검증 시나리오

중복 제출 · 추출 타임아웃 · 식별자 오류 · 후속 등록 실패 · 배포 헬스 체크

04 / 개선 결과

실무에서 달라진 결과.

메일 중심 처리를 통합 접수·버전 관리·자동 검증으로 전환했습니다. FAB당 약 3만~7만 건의 도면을 다루고, 자산·컴포넌트 약 1만 건의 등록을 자동화했습니다.
