3D 디지털 트윈 플랫폼

설비 위치·운영 상태와 MES·MIS·인프라 8개 시스템의 정보를 검색 가능한 3D 업무 공간으로 연결했습니다.

운영주 개발자 · 기술 프로젝트 리드

업무 흐름 이해를 돕기 위해 AI로 생성한 컨셉 이미지이며 실제 시스템 화면은 아닙니다.

8연계 MES·MIS·인프라 시스템
~1.5M연결 자산·컴포넌트
~1,000지원 사용자
개선 전후 ↓처리 흐름 ↓개발 영역 ↓개선 결과 ↓

산업기술보호법 및 회사 보안정책에 따라 세부 구현은 공개하지 않으며, 프로젝트의 전체적인 컨셉과 접근 방식만 설명합니다.

01 / 무엇이 달라졌나

업무 흐름의 개선 전후.

개선 전

설비를 찾은 뒤, 정보를 다시 검색.

  1. 1도면·모델에서 설비 위치 확인
  2. 2각 운영 시스템에 따로 접속
  3. 3식별자와 업무 맥락 수동 연결

물리적 위치와 운영 맥락이 애플리케이션·엔지니어링 자료에 분리돼 있었습니다.

개선 후

설비를 선택하면 관련 맥락을 한곳에.

  1. 13D에서 설비 검색·선택
  2. 2연계 시스템 정보 조회
  3. 3위치·상태·관련 자료 함께 확인

약 2TB의 모델과 엔지니어링·운영 정보를 애플리케이션·연계 계층으로 연결했습니다.

02 / 업무 흐름 속 기술

정보가 시스템을 통과하는 과정.

단계를 선택하면 목적, 구현 기술, 운영상 보호 장치를 확인할 수 있습니다.

모델 맥락 준비

Revit + Python

모델과 설비 정보를 전처리해 검색 가능한 엔지니어링 업무 공간을 준비합니다.

전처리 문제와 사용자 설비 조회 문제를 구분합니다.

검색·선택

3D web workspace

선택한 객체를 설비 식별자·위치·업무에 필요한 정보로 연결합니다.

현재 선택한 설비를 기준으로 정보 요청을 관리합니다.

시스템 연계

REST APIs + MES / MIS

MES·MIS·인프라 8개 시스템의 정보를 공통 운영 맥락에 연결합니다.

정보 소스의 가용 상태와 3D 모델 상태를 별도로 표현합니다.

운영 맥락 표시

Location + status + records

모델과 함께 설비 위치·상태 및 관련 엔지니어링 정보를 표시합니다.

이전에 선택한 설비의 늦은 응답이 현재 맥락을 덮어쓰지 않도록 합니다.

03 / 직접 개발한 영역

설계하고 개발하고 운영한 영역.

PythonREST APIs3D web integrationRevit / BIMACCMES / MIS

애플리케이션·연계 계층

MVP부터 운영 애플리케이션·연계 계층까지 개발해 3D 탐색과 운영 데이터를 연결했습니다.

설비 식별·데이터 연결

약 150만 자산·컴포넌트를 모델 및 시스템 맥락과 연결했습니다.

모델 전처리

약 2TB 모델을 대상으로 Revit 전처리 도구와 설비 위치·상태 시각화를 개발했습니다.

기술 검토·적용

NVIDIA·AVEVA·Siemens와 기술을 검토하고 약 1,000명의 사용자 활용을 지원했습니다.

설계의 핵심 판단

3D 모델은 운영 업무로 진입하는 출발점입니다. 렌더링만큼 설비 식별, 요청 경계, 정보 패널의 독립성이 중요합니다.

예외·검증 시나리오

빠른 설비 선택 전환 · API 응답 순서 역전 · 일부 소스 장애 · 설비 매핑 누락

04 / 개선 결과

실무에서 달라진 결과.

8개 시스템을 검색 가능한 3D 업무 공간으로 연결해 약 1,000명의 사용자를 지원했습니다. 연간 생산성 가치 추정치는 230만 달러입니다.

생산성 가치는 인원 규모·시간당 인건비·효율 개선을 기반으로 추정한 값입니다.
