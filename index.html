AI 지침 파일 / 개발 기준

coding-standards/SKILL.md

API 경계, 입력 검증, 오류 처리, 코드 검토 기준을 지침으로 정리합니다.

AI 지침 파일 / 테스트 생성

test-generation/SKILL.md

정상 경로와 함께 경계 조건, 타임아웃, 중복 요청, 복구 시나리오를 생성하도록 지시합니다.

파일명은 구성 예시입니다. AI가 생성한 변경 사항과 동작을 검토한 뒤 결과를 반영합니다.

여기서 ‘skill’은 AI 에이전트가 읽는 지침 파일을 의미합니다. 이 포트폴리오의 디자인·개발과 콘셉트 이미지에도 AI를 활용했습니다. 실제 구현한 한·영 페이지 전환, 언어 선택 저장, 경력 자동 갱신은 연도 경계와 브라우저 저장소 차단 상황까지 테스트했습니다.
