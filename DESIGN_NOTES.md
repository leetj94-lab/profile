# Portfolio UX revision

## Information architecture
- Home: professional identity, manufacturing IT background, selected work, AI-enabled working approach, brief profile and contact.
- Projects: six direct-linkable HTML pages with a common sticky header and project sidebar.
- Each case study: problem, personal contribution, conceptual direction, practical value.

## Editorial choices
- Name projects directly rather than relying on poetic headlines.
- Remove duplicate technical narratives and the home-page accordion.
- Surface end-to-end ownership and 6+ years of manufacturing IT experience.
- Describe reusable AI skills for UI design, coding criteria, and test generation; disclose AI-assisted creation.
- Keep actual employer implementation details, code and screenshots outside this public portfolio.

## Assets
Original built-in AI-generated concept illustrations are retained in assets/connected-systems.webp and assets/digital-twin.webp. Other illustrations are abstract code-native compositions. None depicts an actual employer system or facility.
