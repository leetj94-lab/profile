API 경계, 입력 검증, 오류 처리, 일관된 개발 기준.

테스트 생성

경계 조건, 중복 요청, 타임아웃, 복구 검증.

파일명은 지침 구성 방식을 보여줍니다. 생성된 UI·코드·테스트 동작을 검토한 뒤 변경을 반영합니다. 이 포트폴리오의 디자인·개발에도 AI를 활용했습니다.
