02 / AI 활용 방식

개발을 가속하는 AI.
일관성을 만드는 개발 기준.

AI로 시스템 개발 방식이 달라졌지만, 생성 코드의 품질은 도메인 이해·엔지니어링 경험·명확한 개발 기준에 달려 있습니다. 재사용 가능한 AI 스킬로 이 기준을 개발 작업 전반에 적용합니다.

UI·API·테스트 스킬에 공통 기준을 담아 AI를 가이드합니다. 기능이나 작업자가 달라져도 생성 코드가 일관된 패턴을 따르고 유지보수 가능한 구조를 갖추도록 활용합니다.

01

문제와 경계를 먼저 정의

현업·개발 경험으로 사용자 요구, 시스템 경계, 수용 기준을 정리한 뒤 코드 생성을 시작합니다.

02

작업마다 같은 스킬 적용

공통 규칙과 예시를 담은 스킬을 반복 적용해 작업자 간 명명·구조·인터페이스를 맞춥니다.

03

기존 코드와 연결되는 구현

공통 컴포넌트와 서비스 패턴을 재사용하고 API 계약과 책임 분리를 유지하도록 AI를 가이드합니다.

04

변경을 검토하고 검증

생성 결과를 공통 기준으로 리뷰하고 수용·경계·복구 조건을 검증합니다. 발견한 개선점은 스킬에 반영합니다.

재사용 가능한 AI 스킬

모든 변경에 적용하는 공통 기준.

AI 코딩 도구가 사용하는 재사용 가능한 지침입니다. 팀의 개발 규칙을 명시해 코드 생성·리뷰·테스트에 같은 기준을 적용합니다.
